# Exp - 6 STUDENT ONLINE EXAM REGISTRATION SYSTEM

# AIM:
To design and understand the working of a Student Online Examination Registration System using UML diagrams.

# SRS (Procedure):
Identify the main actors: Student, Examiner, Admin.
Identify system functions:
Login, Register, View Exams, Take Exam, Answer Questions, Submit Exam, View Results
Create Exam, Add Questions, Publish Exam, Manage Users, Generate Reports
Define relationships between use cases (include, extend).
Draw UML diagrams:
Use Case Diagram
Class Diagram
Sequence Diagram
Activity Diagram
Communication Diagram
Deployment Diagram
Validate system behaviour with actors and use cases.
